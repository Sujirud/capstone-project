## การหมุนและการกลับภาพ

ภาพหน้าตรง test ของ SCUT คู่กับภาพด้านข้างเต็มของ FEI 3 คู่ ที่ผ่านเกณฑ์คุณภาพทั้งคู่ หมุนพิกเซลแล้วใส่ EXIF orientation 3, 6 และ 8 เทียบกับภาพตั้งตรง รวม 27 คำขอ ภาพที่ถอดรหัสแล้วตั้งตรงขนาดเดิม: ผ่าน

| ภาพที่ส่ง | กรามคลาดสูงสุด (จุดเปอร์เซ็นต์) | มุมคลาดสูงสุด (องศา) |
| --- | --- | --- |
| PNG ใส่ EXIF เทียบ PNG ตั้งตรง | 0.00 | 0.00 |
| JPEG 95 ใส่ EXIF เทียบ JPEG 95 ตั้งตรง | 0.30 | 0.50 |
| JPEG 94 ตั้งตรงเทียบ JPEG 95 ตั้งตรง (ไม่หมุน) | 0.10 | 0.50 |
| เกณฑ์ | 0.30 | 0.50 |

PNG ใส่ EXIF ได้ผลเหมือนภาพตั้งตรงทุกค่ายกเว้น `request_id`: ผ่าน ซึ่งเป็นการตรวจขั้นหมุนตาม EXIF ของ api โดยตรง ส่วน JPEG อยู่ในเกณฑ์: ผ่าน ความต่างของ JPEG มาจากการบีบอัดซ้ำ ไม่ใช่การหมุน แถวที่บันทึกภาพตั้งตรงซ้ำโดยไม่หมุนจึงใช้เทียบขนาดของผลนั้น

ภาพด้านข้างเต็มของ FEI 20 ภาพ กลับซ้ายขวาแล้วส่งเป็น PNG วัดได้ทั้งสองแบบ 19 ภาพ วัดได้แบบเดียว 0 ภาพ วัดไม่ได้ทั้งคู่ 1 ภาพ ทิศที่หาได้กลับตามภาพ: ผ่าน เกณฑ์คือมุมคลาดไม่เกิน 0.5° ซึ่งผ่าน 100% ของค่าที่วัดได้ทั้งสองแบบ

| --- | --- | --- | --- |
| Legan | 0.00 | 0.00 | 0.00 |
| nasofacial | 0.00 | 0.00 | 0.00 |
